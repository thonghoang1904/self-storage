# Ảnh trong web

Ảnh chụp thật, đã cắt đúng khung và nén. Thiếu file nào thì web tự hiện hình vẽ thay thế cho chỗ đó.

| File | Nội dung | Dùng ở |
|---|---|---|
| `hero.jpg` (1200×1050) | Dãy kho cửa cuốn màu cam | Ảnh lớn trang chủ, nền trang đăng nhập |
| `units/unit-1.jpg` (1000×600) | Hành lang kho trong nhà, hai dãy cửa cuốn | Tủ Khóa / Locker |
| `units/unit-2.jpg` (1000×600) | Kho số 8 mở cửa, bên trong trống | Kho Nhỏ (S) |
| `units/unit-3.jpg` (1000×600) | Dãy kho cửa cuốn xanh, góc nhà | Kho Vừa / Tiêu chuẩn (M) |
| `units/unit-4.jpg` (1000×600) | Kho lớn cửa cuốn màu cam, có mái che | Kho Lớn (L) |

Ảnh kho dùng ở Trang chủ, Bảng giá, Đặt kho, thẻ Kho Của Tôi, Chi tiết hợp đồng.
Muốn thay ảnh: giữ đúng tên file, tỉ lệ khung như trên, nên dưới 300 KB.
