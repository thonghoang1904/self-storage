# Ảnh trong Figma

Bỏ ảnh xuất từ Figma vào đây đúng tên file. Thiếu file nào thì web tự hiện hình vẽ thay thế cho chỗ đó.

| File | Ảnh trong Figma | Dùng ở |
|---|---|---|
| `units/unit-1.jpg` | Tủ Khóa / Locker | Trang chủ, Bảng giá, Đặt kho, thẻ kho |
| `units/unit-2.jpg` | Kho Nhỏ (S) | như trên |
| `units/unit-3.jpg` | Kho Vừa / Tiêu chuẩn (M) | như trên |
| `units/unit-4.jpg` | Kho Lớn (L) | như trên |
| `hero.jpg` | `hero-photo` ở trang chủ | Ảnh lớn trang chủ, nền trang đăng nhập |

Cách xuất trong Figma: chọn khung ảnh → bảng Export bên phải → định dạng JPG, 2x → Export.
Nên giữ ảnh dưới 300 KB, khoảng 1200 px chiều ngang.
